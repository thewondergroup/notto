NOTTO site update

WHAT CHANGED
  All 15 pages  -> Google Tag Manager container GTM-MXS835JV added.
                   Head snippet first thing inside <head>, noscript
                   iframe immediately after <body>, per Google's spec.
  site.js       -> deep links added:
                   nottopasta.com/#vouchers opens the gift card widget
                   nottopasta.com/#loyalty  opens the loyalty sign-up

HOW TO DEPLOY
  Drop these files into the repo root, replacing the existing ones.
  Then re-run the test in the Google Tag Manager install dialog.

NOTE ON GA4
  The hardcoded GA4 gtag (G-V3E3VKTVLT) has been removed from every page.
  GA4 now loads only through GTM, as a Google Tag for G-V3E3VKTVLT
  published in container GTM-MXS835JV. Do not add the gtag back,
  or every visit will be counted twice.
